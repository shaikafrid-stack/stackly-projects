# Screenshots

This folder is where the required submission screenshots should be placed once the app is run locally:

1. Login screen
2. Dashboard / Summary
3. Dataset List
4. Dataset Overview
5. Version History
6. Version Details
7. Compare Versions
8. Dataset Lineage
9. Change History
10. Restore Version Confirmation modal

Start both servers (`npm run dev` in `backend/` and `frontend/`), walk through each screen listed above, and save a `.png` for each here (e.g. `01-login.png`, `02-dashboard.png`, …).
